# FlickOff
## I'm curious why FPS games don't use databases as first-layer anticheat.
## I get that it's an ongoing cost but surely it's cheaper than kernel anticheat development.

Therefore I will be creating a simple browser game that functions as an aim-trainer:
1. There will be 3 levels.
2. Enemies will spawn in random locations on those levels, with random elevations.
3. The player is initially out-of-sight of the enemies and must peek them.
4. The best runs will be displayed on a leaderboard.
5. Everything is saved to the database. Everything.
6. We'll see what we learn!
