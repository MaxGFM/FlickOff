# Notes that may be applicable to not just me:

## running the game on Linux locally either native or web
1. Run ./dev.sh then interrupt the Go server using CTRL-C if it doesn't fail
2. Run either 'make redo' or just 'make up' to get Postgres DB schema
3. Run ./dev.sh again
4. In a new terminal, run either ./web.sh or ./nat.sh
## If web - ./web.sh:
5. Open your web browser and navigate to localhost:4000
^ Go is serving our files and acting as our server, we can skip Python
## If native - ./nat.sh:
5. Run ./game_desktop.bin within the build/local directory
